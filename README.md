# loop-virtuoso has moved

This plugin now lives inside the Code Virtuoso repository at
[`plugins/loop-virtuoso`](https://github.com/krzysztofsurdy/code-virtuoso/tree/main/plugins/loop-virtuoso),
released there as loop-virtuoso 2.0.0. This repository is archived and gets no further updates.

Install the current version:

```
/plugin marketplace add krzysztofsurdy/code-virtuoso
/plugin install loop-virtuoso@code-virtuoso
```

If you installed `loop-virtuoso@loop-virtuoso`, uninstall it first. On the first run the new version
moves an existing `.delivery-loop/` directory to `.code-virtuoso/loop/` once.
